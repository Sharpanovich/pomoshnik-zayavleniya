# Помощник по заявлениям

Программа для подготовки и исправления заявлений о возбуждении исполнительного производства в ОСП по г. Камышину (ООО «ЛУКОЙЛ-Волгоградэнерго»).

---

## 📁 Структура проекта (файлы для переноса на новый ПК)

1. **`Помощник по заявлениям.exe`** — готовая к работе программа (не требует установки).
2. **`Загрузка на GitHub.exe`** — утилита для быстрой публикации проекта и создания официальных релизов на GitHub.
3. **`App.cs`** — полный исходный код приложения (C#, Windows Forms).
4. **`GitHubUploader.cs`** — исходный код загрузчика на GitHub.
5. **`release_notes.txt`** — описание текущей версии и текст релиза (автоматически подгружается в загрузчик).
6. **`app.ico`** — иконка приложения.
7. **`СБОРКА ПРОГРАММЫ.bat`** — запуск компиляции программ на новом ПК в 1 клик.
8. **`build.ps1`** — сценарий PowerShell для компиляции через штатный компилятор Windows (`csc.exe`).
9. **`улицы.txt`** — самообучающаяся база улиц и микрорайонов г. Камышина (более 80 адресов).
10. **`Шаблоны\`** — папка с эталонным образцом заявления (`094729862.docx`).
11. **`Новые заявления\`** — папка, куда генератор сохраняет готовые файлы Word.
12. **`Исходные заявления\`** — папка для входящих файлов Word, требующих исправления реквизитов.
13. **`Исправленные заявления\`** — папка для готовых исправленных документов.

---

## 🚀 Как запустить на новом ПК

1. Скопируйте всю папку на новый компьютер (на Рабочий стол или диск C: / D:).
2. Запустите файл **`Помощник по заявлениям.exe`** (двойным кликом).
3. Программа работает на Windows 7 / 8 / 10 / 11 без установки сторонних программ (используется встроенный в Windows .NET Framework 4.8).

---

## 🔨 Как пересобрать программу из исходного кода на новом ПК

Если вы внесли изменения в `App.cs` или `GitHubUploader.cs` или хотите пересобрать `.exe` с нуля:
* **Просто дважды кликните по файлу `СБОРКА ПРОГРАММЫ.bat`**.
* Программа сама найдет встроенный компилятор `csc.exe` в Windows и за 2 секунды создаст обновленные файлы `Помощник по заявлениям.exe` и `Загрузка на GitHub.exe`.

## ⚡ Особенности генератора (версия 1.1.0)

* **Файлы сохраняются строго по номеру дела:** `530344047.docx` (без лишних приставок).
* **Фиксированный город:** `403870, Волгоградская обл, Камышин г` проставляется автоматически.
* **Свобода раскладки клавиатуры:** программа не сбрасывает язык Windows на русский; оператор может свободно вводить текст на любой раскладке.
* **Поддержка дробей, точек и спецсимволов в адресе:** адреса `1/7`, `3.4`, `8,3`, литерные `17А` сохраняются без искажений. При наборе адреса на русской раскладке клавиша `\` автоматически подставляет прямой слэш `/`.
* **Авто-КАПС и умная транслитерация:** ФИО и адресные поля пишутся заглавными буквами, случайный ввод на латинице исправляется на русский язык без искажения цифр и знаков.
* **Авто-приписка улицы:** при вводе названия (например, `Ленина`) автоматически дописывается `ул`.
* **Формат дома:** всегда пишется полностью `дом №17` (вместо `д. 17`).
* **Комната:** галочка `[ ] комн.` для комнат в общежитиях/коммунальных квартирах.
* **Тестовые данные в 1 клик:** кнопка `🎲 Тестовые данные` (`Ctrl + Shift + T` / `F12`) мгновенно заполняет форму демонстрационными реквизитами для быстрой проверки.
* **Быстрый ввод:** навигация по `Tab` и создание заявления по `Enter`. Курсор сам возвращается в поле «Номер дела».

## 🌐 Публикация и создание Релизов на GitHub

Для быстрой публикации программы или выпуска обновлений:
1. Запустите файл **`Загрузка на GitHub.exe`**.
2. Вставьте GitHub Personal Access Token (с правом `repo`).
3. Версия `v1.1.0`, название и описание релиза **уже заполнены автоматически** из файла `release_notes.txt` (также есть кнопка быстрого сброса «✨ Данные v1.1.0» и «📂 Из release_notes.txt»).
4. Нажмите **«🚀 Загрузить проект и опубликовать Релиз на GitHub»**.
5. Программа:
   * Отправит чистый исходный код в ветку `main` (персональные данные должников защищены `.gitignore`).
   * Создаст официальный GitHub Release с красивым описанием.
   * Автоматически прикрепит к релизу готовый **`Помощник по заявлениям.exe`** и ZIP-архив для скачивания в 1 клик на любом компьютере!
