# Помощник по заявлениям

Программа для подготовки и исправления заявлений о возбуждении исполнительного производства в ОСП по г. Камышину (ООО «ЛУКОЙЛ-Волгоградэнерго»).

---

## 📁 Структура проекта (файлы для переноса на новый ПК)

1. **`Помощник по заявлениям.exe`** — готовая к работе программа (не требует установки).
2. **`Загрузка на GitHub.exe`** — утилита для быстрой публикации проекта и создания официальных релизов на GitHub.
3. **`App.cs`** — полный исходный код приложения (C#, Windows Forms).
4. **`GitHubUploader.cs`** — исходный код загрузчика на GitHub.
5. **`app.ico`** — иконка приложения.
6. **`СБОРКА ПРОГРАММЫ.bat`** — запуск компиляции программ на новом ПК в 1 клик.
7. **`build.ps1`** — сценарий PowerShell для компиляции через штатный компилятор Windows (`csc.exe`).
8. **`улицы.txt`** — самообучающаяся база улиц и микрорайонов г. Камышина (более 80 адресов).
9. **`Шаблоны\`** — папка с эталонным образцом заявления (`094729862.docx`).
10. **`Новые заявления\`** — папка, куда генератор сохраняет готовые файлы Word.
11. **`Исходные заявления\`** — папка для входящих файлов Word, требующих исправления реквизитов.
12. **`Исправленные заявления\`** — папка для готовых исправленных документов.

---

## 🚀 Как запустить на новом ПК

1. Скопируйте всю папку на новый компьютер (на Рабочий стол или диск C: / D:).
2. Запустите файл **`Помощник по заявлениям.exe`** (двойным кликом).
3. Программа работает на Windows 7 / 8 / 10 / 11 без установки сторонних программ (используется встроенный в Windows .NET Framework 4.8).

---

## 🔨 Как пересобрать программу из исходного кода на новом ПК

Если вы внесли изменения в `App.cs` или хотите пересобрать `.exe` с нуля:
* **Просто дважды кликните по файлу `СБОРКА ПРОГРАММЫ.bat`**.
* Программа сама найдет встроенный компилятор `csc.exe` в Windows и за 2 секунды создаст обновленный файл `Помощник по заявлениям.exe`.

## ⚡ Особенности генератора

* **Файлы сохраняются строго по номеру дела:** `530344047.docx` (без лишних приставок).
* **Фиксированный город:** `403870, Волгоградская обл, Камышин г` проставляется автоматически.
* **Авто-КАПС:** ФИО и адресные поля автоматически пишутся заглавными буквами.
* **Авто-приписка улицы:** при вводе названия (например, `Ленина`) автоматически дописывается `ул`.
* **Формат дома:** всегда пишется полностью `дом №17` (вместо `д. 17`).
* **Комната:** галочка `[ ] комн.` для комнат в общежитиях/коммунальных квартирах.
* **Всегда русский язык (независимо от раскладки):** при переходе в поля ФИО и адреса Windows автоматически переключает раскладку на русскую (`ru-RU`), а если вы случайно набрали текст на английской раскладке (например, `bdfyjd` или `ktybyf`), программа на лету переводит его в русский язык (`ИВАНОВ`, `ЛЕНИНА`).
* **Быстрый ввод:** навигация по `Tab` и создание заявления по `Ctrl + Enter` или `Enter`. Курсор сам возвращается в поле «Номер дела».

## 🌐 Публикация и создание Релизов на GitHub

Для быстрой публикации программы или выпуска обновлений:
1. Запустите файл **`Загрузка на GitHub.exe`**.
2. Вставьте GitHub Personal Access Token (с правом `repo`).
3. При необходимости укажите версию релиза (например: `v1.0.0`, `v1.0.1`) и отредактируйте список изменений («Что нового»).
4. Нажмите **«🚀 Загрузить проект и опубликовать Релиз на GitHub»**.
5. Программа:
   * Отправит чистый исходный код в ветку `main` (персональные данные должников защищены `.gitignore`).
   * Создаст официальный GitHub Release с красивым описанием.
   * Автоматически прикрепит к релизу готовый **`Помощник по заявлениям.exe`** и ZIP-архив для скачивания в 1 клик на любом компьютере!
